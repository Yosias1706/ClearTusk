How it works

Four stages, every one measured

01

Detect

A gradient-boosted classifier sweeps 1.5-second windows and marks where calls actually occur, with a confidence per event.

02

Profile

The dominant event picks the call profile — rumble, roar, or trumpet — which fixes the frequency band that must be protected.

03

Isolate

Harmonic/percussive separation, ridge masking, and a noise gate run once per preset; the highest scoring candidate wins.

04

Score

Retention, suppression, call-to-noise gain, and spectral fidelity are stored with every run so quality is tracked over time.
